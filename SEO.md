# 01. 🌱 SEO MISSION & STRATEGIC FOUNDATION

## 1.1 — The Mission

PotGrowHub.store exists to make useful cannabis knowledge, cultivation education, creative exploration, sustainability information, and responsible product discovery easier to find and understand.

SEO is the infrastructure that connects genuine visitor needs with relevant, useful, trustworthy public resources.

The mission is not simply to attract clicks. The mission is to help visitors find answers, understand options, complete meaningful tasks, and discover the next useful step.

## 1.2 — The SEO North Star

> 🌿 **We win when a visitor stops searching and starts talking to GanjaGuru — then stays to grow.**

Organic discovery should create a natural path from search intent to a meaningful guided session.

A visitor might arrive looking for a terpene definition, learn how terpene profiles are described, explore a related guide, and use GanjaGuru to organize follow-up questions.

Another visitor might arrive looking for a cultivation concept, learn the fundamentals, and create a practical checklist.

A third visitor might explore an accessory category and leave with a clearer understanding of compatibility, materials, or care.

Every journey should prioritize usefulness over unnecessary friction.

# 06. ⚙️ TECHNICAL SEO & CRAWLABILITY

## 6.1 — HTTP and HTTPS

- Serve public pages over HTTPS.
- Redirect HTTP to the preferred HTTPS URL.
- Select one canonical hostname.
- Avoid redirect chains.
- Prevent redirect loops.
- Return accurate status codes.
- Do not redirect every missing page to the homepage.
- Keep internal links pointed directly at final destinations.

## 6.2 — HTTP Status Code Reference

| Code | Meaning | SEO Handling |
|---|---|---|
| `200` | Successful response | Appropriate for valid pages |
| `301` | Permanent redirect | Use for permanent URL moves |
| `302` | Temporary redirect | Use for temporary changes |
| `304` | Not modified | Supports conditional requests |
| `400` | Bad request | Validate request handling |
| `401` | Authentication required | Protect private resources |
| `403` | Forbidden | Restrict unauthorized access |
| `404` | Not found | Return for missing resources |
| `410` | Gone | Use when content is intentionally removed |
| `429` | Rate limited | Protect service capacity |
| `500` | Server error | Investigate and repair |
| `503` | Temporarily unavailable | Use for genuine temporary outages |

## 6.3 — robots.txt

Expected location:

`https://potgrowhub.store/robots.txt`

Requirements:

- Use valid robots directive syntax.
- Reference the correct sitemap URL.
- Avoid accidentally blocking important resources.
- Review every disallow rule.
- Do not put secrets in the file.
- Do not treat robots.txt as an access-control system.
- Validate after deployment.

## 6.4 — XML Sitemap

Expected location:

`https://potgrowhub.store/sitemap.xml`

Include eligible canonical URLs that:

- Are intended for indexing.
- Return successful responses.
- Are not redirects.
- Are not marked `noindex`.
- Are not blocked from crawling.
- Contain useful content.

Use valid XML. Include `lastmod` only when a meaningful page update occurs.

`changefreq` and `priority` are optional and should not be treated as reliable ranking controls.

For larger websites, split sitemaps by content type and use a sitemap index where appropriate.

## 6.5 — Canonicalization

Use an absolute canonical URL on indexable pages where appropriate.

Example:

```html
<link
  rel="canonical"
  href="https://potgrowhub.store/cultivation/plant-health/"
/>
```

Requirements:

- Use the preferred HTTPS hostname.
- Point to the correct final URL.
- Keep canonicals consistent with internal links.
- Avoid conflicting declarations.
- Avoid canonicalizing unrelated pages together.
- Do not use canonicalization to protect private information.

## 6.6 — Crawl Efficiency

- Remove unnecessary URL variants.
- Avoid infinite filter combinations.
- Control duplicate query-parameter URLs.
- Keep internal links crawlable.
- Remove broken navigation paths.
- Avoid creating empty category pages.
- Monitor crawl reports.
- Review server logs when available and appropriate.

# 07. 🏷️ ON-PAGE SEO & METADATA

## 7.1 — Required Page-Level Elements

Important indexable pages should have:

- A unique title.
- A relevant meta description.
- A clear primary heading.
- Logical heading hierarchy.
- Correct language metadata.
- A canonical URL where appropriate.
- Descriptive image alternatives.
- Relevant internal links.
- Appropriate robots directives.
- Valid structured data when applicable.

## 7.2 — Title Tag Standards

Use clear, page-specific titles. Approximately 50–60 characters can be a useful drafting target, but display width varies.

Examples:

- `Cannabis Cultivation Basics | PotGrowHub.store`
- `Cannabinoids Explained | PotGrowHub.store`
- `GanjaGuru AI Guide | PotGrowHub.store`
- `Sustainable Growing Practices | PotGrowHub.store`

These examples do not imply that the pages currently exist.

## 7.3 — Meta Description Standards

Write concise descriptions that explain the actual page and its value. Approximately 140–160 characters can be a useful starting point, not a strict rule.

Example:

`Explore cannabis education, cultivation fundamentals, and practical sustainability guidance with PotGrowHub.store.`

Avoid:

- Keyword stuffing.
- Misleading promises.
- Unsupported claims.
- Identical descriptions across all pages.
- Descriptions unrelated to visible content.

Search engines may generate their own snippets.

## 7.4 — Heading Hierarchy

- Use a clear `<h1>` for the primary page topic.
- Use `<h2>` for major sections.
- Use `<h3>` for meaningful subsections.
- Keep headings descriptive.
- Do not select heading levels solely for visual size.
- Avoid mechanically repeating the same keyword.
- Ensure headings accurately represent the content that follows.

## 7.5 — Open Graph Metadata

Where social sharing is useful, provide accurate values for:

- `og:title`
- `og:description`
- `og:type`
- `og:url`
- `og:image`
- `og:site_name`

Use a real, accessible image URL and ensure the preview accurately represents the page.

## 7.6 — Link Text

Prefer descriptive anchors such as:

- `cannabis plant anatomy`
- `understanding terpene profiles`
- `cultivation environment fundamentals`
- `GanjaGuru privacy information`

Avoid repetitive generic anchors when a meaningful description is available.

# 09. 🌿 CANNABIS CONTENT ACCURACY & RESPONSIBLE COMMUNICATION

## 9.1 — Scientific Accuracy

Cannabis-related information can vary by cultivar, growing conditions, processing, formulation, dose, route of administration, and individual response.

Distinguish clearly between:

- Established findings.
- Preliminary research.
- Anecdotal reports.
- Commercial descriptions.
- Personal preferences.
- Unverified claims.

## 9.2 — Strain Information

When publishing strain profiles, document where available:

- Name and aliases.
- Reported lineage.
- Breeder attribution.
- Reported cannabinoid values.
- Reported terpene profile.
- Cultivation characteristics.
- Source and date.
- Uncertainty and variability.

Do not represent unverified lineage, potency, effects, or medicinal benefits as established facts.

## 9.3 — Health Claims

- Avoid unsupported disease-treatment or cure claims.
- Do not guarantee specific effects.
- Distinguish educational information from medical advice.
- Encourage qualified medical guidance for health concerns.
- Explain uncertainty where research is limited.
- Prefer reputable primary research and authoritative health sources.

## 9.4 — Responsible-Use Education

Where relevant, explain:

- Impairment and driving risks.
- Risks for adolescents.
- Pregnancy and breastfeeding considerations.
- Potential medication interactions.
- Safe storage away from children and pets.
- Accidental ingestion risks.
- Individual variability.
- When professional assistance is appropriate.

## 9.5 — Legal Context

- Remind readers to verify current local laws.
- Do not assume legality across jurisdictions.
- Cite official sources for location-specific claims.
- Date legal information when appropriate.
- Avoid representing general education as legal advice.
- Recheck information that may change.

# 11. 🧠 ANSWER ENGINE OPTIMIZATION (AEO)

## 11.1 — AEO Mission

Make important information easy to understand, extract, verify, and navigate.

AEO supports clear answers for visitors and systems that summarize public information. It does not guarantee placement in a featured snippet, AI overview, or generated answer.

## 11.2 — Answer-First Structure

For question-focused pages:

1. Present a direct answer near the beginning.
2. Define essential terminology.
3. Explain context.
4. Provide supporting evidence.
5. Identify uncertainty.
6. Include useful examples.
7. Link to deeper explanations.
8. State relevant safety or legal limitations.

## 11.3 — Question-Based Headings

Use natural questions when they reflect real visitor needs.

Examples:

- What are cannabinoids?
- How are terpenes described?
- What affects a growing environment?
- How should product compatibility be evaluated?
- What can GanjaGuru help with?
- How does PotGrowHub.store handle uploaded files?

Only answer questions that the site can address accurately.

## 11.4 — FAQ Standards

- Use genuine visitor questions.
- Keep answers direct.
- Avoid duplicating identical FAQs across unrelated pages.
- Ensure answers match the main article.
- Avoid unsupported guarantees.
- Apply `FAQPage` structured data only when appropriate and compliant with current eligibility rules.

## 11.5 — Definitions and Lists

Use definitions, tables, and lists when they improve comprehension.

Examples include:

- Glossaries.
- Comparison tables.
- Step-by-step educational procedures.
- Troubleshooting guides.
- Safety checklists.
- Terminology references.

Do not restructure content solely to manipulate search snippets.
