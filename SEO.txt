5. META ROBOTS AND INDEXING
======================================================================

Default indexable public pages:
<meta name="robots" content="index,follow">

Apply index,follow only where the page is intended to be publicly indexed. Search engines generally treat these directives as defaults, so avoid unnecessary repetition.

Use noindex for appropriate private or low-value pages, such as:
- Account pages containing personal information.
- Login and registration screens where indexing has no user value.
- Private dashboards.
- Internal search-result pages when they create large numbers of low-value URLs.
- Temporary preview pages.
- Staging environments.
- Duplicate utility pages that should not appear in search results.

Requirements:
- Do not block a URL in robots.txt if a crawler must fetch the page to discover its noindex directive.
- Protect private content with real authentication and authorization. Noindex is not security.
- Do not use noindex as a substitute for canonicalization.
- Do not accidentally apply noindex sitewide.
- Check meta robots tags and X-Robots-Tag response headers.
- Use nofollow only when there is a specific, justified reason.
- Avoid contradictory indexing instructions across HTML, headers, canonical tags, and sitemap entries.
- Keep robots directives consistent with the intended public visibility of each page.
